## 1. Input Processing

**Received Materials:**
- 聊天记录截图 / 转账记录 / 对话文本
- 原告/被告身份
- 争议金额
- 核心争议点

**Parsing Steps:**
1. 识别证据类型（截图/文字/表格）
2. 标注时间节点
3. 提取关键词（借、还、息、周转、投资、分红）
4. 分类归入四大证据类目：
   - 交付证据（转账记录）
   - 合意证据（借款约定聊天）
   - 催收/确认证据（还款承诺/追讨记录）
   - 主体资格证据（身份信息）

## 2. Evidence Chain Mapping

**优先证据链：**
```
借款提议（聊天）→ 转账交付（记录）→ 对方确认收到（聊天）→ 利息约定（聊天）→ 催款记录 → 还款承诺
```

**30分钟窗口原则：**
- 某笔转账缺乏直接聊天对应
- 查找转账前后30分钟内对话
- 或以长期交易习惯推定资金性质
- 标注"时间戳 | 转账金额 | 对应聊天索引"

**证据链缺口补全策略：**
- 缺口：转账无对应聊天 → 寻找相近时间窗口聊天或依赖交易习惯推定
- 缺口：利息约定不明 → 依民间借贷惯例（年利率15-20%为参考）
- 缺口：还款承诺缺失 → 以催款回复中的自认作为债务确认

## 3. Module Output Templates

### 模块一：核心文书

#### 起诉状草稿模板
```
原告：XXX（姓名/名称），住所地XXX
被告：XXX（姓名/名称），住所地XXX

诉讼请求：
1. 被告返还借款本金人民币XX元
2. 被告支付借款利息（暂计至XX年XX月XX日为XX元）
3. 被告承担本案诉讼费用

事实与理由：
原告与被告系XXX关系。XX年XX月XX日，被告因XXX需要向原告借款，原告于同日通过XX银行/支付宝/微信转账方式向被告指定账户（户名：XXX，账号：XXX）转账XX元。双方口头约定利息为月息X%/年息X%，未约定还款期限。

此后被告仅支付利息至XX年XX月XX日，此后未再还本付息。原告多次催收，被告于XX年XX月XX日承诺于XX时还款，但至今未履行。

依据《民法典》第X条及《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》，诉请如上。
```

#### 证据清单模板
| 序号 | 证据名称 | 来源 | 证明对象 | 页码 |
|------|---------|------|---------|------|
| 1 | 转账记录（支付宝/微信/银行） | 原告提供 | 证明借款交付事实 | P1-3 |
| 2 | 聊天记录截图（借款合意） | 原告提供 | 证明借款合意及利息约定 | P4-7 |
| 3 | 聊天记录截图（催收确认） | 原告提供 | 证明被告承认债务 | P8-10 |
| 4 | 主体身份证明 | 原告提供 | 证明原被告诉讼主体资格 | P11 |

#### 代理词提纲
```
一、本案法律关系性质：民间借贷
  （一）借款合意成立
  （二）借款交付完成
  （三）利息约定明确

二、关于被告抗辩的回应
  （一）投资论不成立——无管理参与/分红记录/书面协议
  （二）亏损共担论不成立——无风险共担安排
  （三）旧账论不成立——对方未能举证

三、利息计算的合理性
  （一）法定上限：合同成立时LPR×4
  （二）原告主张：月息X%（折合年化X%）
  （三）未超过法定上限部分应予支持

四、结论意见
```

## 4. Evidence Qualification (证据三性)

### 逐条评估模板
| 证据 | 真实性 | 合法性 | 关联性 | 综合评价 |
|------|--------|--------|--------|---------|
| 转账截图 | ✅ 平台原始记录 | ✅ 合法的 | ✅ 直接证明借款交付 | 可用 |
| 聊天截图 | ⚠️ 需核验完整性 | ✅ | ✅ 证明合意 | 需确保未被删减 |
| 录音 | ⚠️ 需确认当事人 | ⚠️ 需合法录制 | ✅ | 需确认录制合法 |

### 关键信号提取清单

**✅ 默示自认语句：**
- "最近手头紧" → 未否认借款，仅对时间提异议 → 构成债务自认
- "欠你的会还" → 明确承认债务存在
- "本金收到了，利息缓一下" → 确认本金，承认利息义务

**✅ 固定付息行为：**
- 每月固定日期支付固定金额 → 高度符合"规律性付息"特征
- 民间借贷核心特征之一：规律性还息

**✅ 生活化语言 → 法律语言翻译：**
| 生活化表达 | 法律定性 |
|-----------|---------|
| "月底还你" | 还款期限约定 |
| "利息怎么算" | 利息合意形成 |
| "周转不开" | 借款原因/必要性 |
| "保本金" | 保底条款（效力待定） |

**✅ 金额吻合度 & 行为一致性：**
- 转账金额与聊天提及金额是否一致
- 付息金额是否符合约定利率推算
- 时间间隔是否规律（规律付息 → 借贷推定）

## 5. Defense Construction (辩论防御)

### 预判对方抗辩点

#### 抗辩1：投资论
**对方可能主张：** 案涉款项系投资款，非借款，风险共担，亏损应共担
**我方反击：**
1. 追问有无书面投资协议 → 无 → 投资关系不成立
2. 追问有无参与管理决策 → 无 → 不符合投资特征
3. 追问有无利润分红记录 → 无 → 投资应有分红
4. 主张：**"名为投资，实为借贷"** — 仅有资金投入，无管理参与，无分红约定，符合借贷特征
5. 固定付息行为 → 投资不应有固定回报 → 推定为借贷

#### 抗辩2：亏损共担论
**对方可能主张：** 款项用于共同投资，亏损应共同承担
**我方反击：**
1. 有无风险共担协议 → 无
2. 有无亏损发生证明 → 单方陈述无效
3. 主张：**保底条款效力** — 即使存在保底安排，依《民间借贷司法解释》第12条，稳定收益条款可被认定为借贷
4. 追问对方是否曾抱怨亏损 → 固化证据

#### 抗辩3：旧账论
**对方可能主张：** 该笔款项系偿还旧账，非新借款
**我方反击：**
1. 要求对方提供旧账证据链（借条/转账记录/聊天）
2. 逐笔核对旧账金额是否与本案金额吻合
3. 反向举证：原告从未欠被告款项

#### 抗辩4：已还清论
**对方可能主张：** 已通过现金/转账全部还清
**我方反击：**
1. 逐笔核对还款记录 vs 本金+利息
2. 计算差额，主张未还清金额
3. 要求对方提供还款凭证

#### 抗辩5：时效抗辩
**对方可能主张：** 借款已过诉讼时效
**我方反击：**
1. 审查最后一次还款/承诺时间
2. 催款记录构成时效中断
3. 起诉距最后中断未满三年

### 诚信危机证据提取
1. **态度变化：** 从主动求助 → 承诺还款 → 拖延 → 失联
2. **失联行为：** 拉黑/不回消息/电话不接
3. **对他人欠款：** 同类案件判决书/被执行人记录（必要时申请调取）
4. **前后矛盾：** 借款时说"月底还"，催款时说"手头紧"，失联前说"会还" → 前后矛盾，诚信度低

### 针对性辩护话术（可直接庭审使用）

**开场陈述：**
"审判长/法官，本案系民间借贷纠纷。原告提交证据显示，2023年X月X日，被告因周转需要向原告借款，原告通过转账方式向被告出借款项人民币X元。被告借款后，按月支付利息至2023年X月，此后停止付息，原告多次催收，被告承认债务但未履行。"

**针对"投资论"：**
"对方主张案涉款项为投资款，但未能提供任何书面投资协议，亦无证据证明其参与管理或分享利润。相反，被告规律性支付固定利息，符合借贷关系中'付息还本'的核心特征。因此，案涉款项名为投资，实为借贷。"

**针对"亏损共担论"：**
"退一步讲，即使存在亏损共担安排，依司法解释相关规定，提供资金并收取固定收益的一方，有权主张借贷关系。被告按月支付固定利息的事实，充分证明案涉关系为借贷。"

**针对"已还清论"：**
"对方主张已还清全部款项，但未能提供任何还款凭证。根据原告提交的转账记录，被告累计支付利息X元，与其应付利息存在差额。请求法院责令被告提供完整银行流水，以便查明真相。"

**总结陈词：**
"综上，原告提交的证据形成完整证据链，证明借贷合意成立、借款交付完成、被告规律付息、债务承认明确。被告未能举证证明其抗辩主张，请求法院支持原告全部诉讼请求。"

## Quick Reference Card

```
输入：材料（聊天+转账+身份）+ ①原告/被告 + ②金额 + ③争议点
处理：解析→分类→时间轴→证据链→三性评估
输出：五模块案卷包

核心原则：
  证据链优先于孤立截图
  30分钟窗口原则
  默示自认识别
  去噪保留备查

路由：
  投资论 → 追问协议/管理/分红 → "名为投资实为借贷"
  亏损共担 → 追问风险协议 → 保底条款无效
  旧账论 → 要求对方举证 → 反向举证
  已还清 → 逐笔核对 → 找出差额
```
